A community developer has released a Decky Loader plugin that makes the Steam Deck's Game Mode look like the Xbox Series X|S dashboard. To be clear: this is an independent fan project published on GitHub by kromossomom. It isn't made or endorsed by Valve or Microsoft.

## What it does

According to the project's GitHub page, Decky Xbox Dashboard replaces Steam's home screen with an Xbox-style layout:

- **Home screen:** the focused game's art fills the screen, with rows for recent games, Pinned, Installed and Shortcuts.
- **Tabs:** Home, My games & apps, Store, Community and System, switched with LB and RB. B goes back to Home.
- **Game pages:** press Y on a tile for a game hub with a Play button, Steam Deck compatibility, Metacritic and size badges, achievements with progress, and HowLongToBeat times.
- **Pinning and customization:** press X to pin games, choose what fills Home's rows, and hide games from Home.
- **Xbox look across Steam:** Steam's blue accents become Xbox colors, with Guide-style menus and a Series X|S-style focus ring.
- **Languages:** English and Portuguese, following Steam's language setting.

It's open source under the MIT license and still early: the latest release is labeled v0.0.9-alpha, published October 28. Windows Central notes that the developer used Claude AI to help with development.

## Installing it

The plugin requires Decky Loader, the community plugin loader for SteamOS. Per the README, download xbox-dashboard.zip from the GitHub repo on your Deck, then open Quick Access, go to Decky, open settings, turn on Developer mode under General, and use "Install Plugin from ZIP." Since it isn't in the Decky plugin store and is an alpha, expect rough edges.
