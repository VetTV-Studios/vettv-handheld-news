Microsoft released new Windows 11 Insider Preview builds on October 30 to the Beta and Experimental channels.

## The builds

- **Beta:** Build 26220.9836
- **Experimental:** Build 26340.9843
- **Beta (26H1):** Build 28020.3382
- **Experimental (26H1):** Build 28120.3393
- **Experimental (Future Platforms):** Build 29698.1000

## The new Windows Search grows

For Insiders in the Experimental and Experimental (26H1) channels, Microsoft is expanding the redesigned Windows Search that started rolling out earlier this month:

- **Inline actions:** sliders for volume, screen brightness and cursor size right in the results, plus suggested actions.
- **Phone actions:** with a phone connected through Phone Link, you can call or text and use actions like Do Not Disturb. Android works now, and Microsoft says iPhone support is coming early next year.
- **Richer results:** file previews with details like last modified date, location and author, web answers for weather, stocks and facts, and apps and games from the Microsoft Store. Store results can be turned off in Settings > Privacy & security > Search.
- **Result filters:** filter by Files & Folders, Settings, Actions and more.
- **Feedback controls:** thumbs up or down on results, and you can remove items from the starting Search view.

The new Search opens at the bottom center of the screen for now. Microsoft says it's working on adapting it to different taskbar positions and to searching from the Start menu.

## Private feedback for businesses

A new Intune policy lets commercial customers keep Feedback Hub submissions from their users private. With it on, feedback can't be posted to the public community or shared outside the organization, and only Microsoft and people in the same tenant can see it.
