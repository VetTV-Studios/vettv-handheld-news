Epic's in-development Games Launcher Preview, the build that runs natively on Linux, picked up two more updates this week, and the bigger fix is for Linux users who couldn't get in at all.

## Version 0.106.0 (October 29)

Epic's changelog says a locked system keyring could previously stop the launcher from starting or sign the user out. GamingOnLinux reports that many users ran into this, with some unable to open the launcher and others unable to log in. Version 0.106 fixes it. The same release fixes a Linux bug where the chat notification setting wasn't recognized, and an issue where Library, catalog and cover images sometimes failed to load on slower networks. Fab's plugin search now filters results to the Unreal Engine version it was opened from.

## Version 0.105.0 (October 28)

- A game and the DLC you own for it now install together in one operation.
- On Linux, local Unreal Engine installs can now be opened from the launcher.
- One-click installs now follow the shortcut choice made in the install dialog.
- The Library no longer sometimes shows an incomplete game list after an interrupted scan.
- Unreleased games now show as Unavailable when preloads are turned off.

## The pace so far

Epic has shipped six numbered preview builds, 0.101 through 0.106, between October 22 and October 29. Earlier builds added waiting for the network instead of failing a download, automatic update checks when you press Play, and updating a game with a pending patch before it launches. The launcher is still labeled a preview.
