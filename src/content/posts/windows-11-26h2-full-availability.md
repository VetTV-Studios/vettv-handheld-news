Microsoft has finished the phased rollout of **Windows 11 version 26H2**, the Windows 11 2026 Update. Its [release health page](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-26h2), current as of **October 21, 2026**, says the rollout "has reached full availability for devices running Windows 11, versions 25H2 and 24H2." [Windows Latest](https://www.windowslatest.com/2026/10/27/microsoft-confirms-windows-11-26h2-is-now-available-for-everyone-and-it-installs-in-under-five-minutes/) spotted the change.

"Everyone" here means eligible PCs already on 24H2 or 25H2. Windows 10 PCs and older Windows 11 versions aren't covered. Microsoft can also still place **safeguard holds** on devices with a known compatibility issue.

## How to get it

Go to **Settings > Windows Update** and select **Check for Windows updates**. If 26H2 is offered, select **Download & install**. Microsoft says a single restart finishes the job. To check what you're on now, look under **Settings > System > About**. Windows Latest says 26H2 shows as build 26300.

## Why it's so small

Microsoft says 26H2 includes the features already announced for 24H2 and 25H2 and is delivered "using servicing technology." In practice it's an enablement package that switches on code your PC already has. Windows Latest measured the package at 174KB and says it installed in under five minutes in its tests. Don't expect visible changes.

## Why you might want it anyway

It resets the support clock. Microsoft's [24H2 status page](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-24h2) says Home and Pro editions of 24H2 stopped getting updates on **October 13, 2026**. According to Windows Latest, 26H2 Home and Pro are supported until **October 9, 2028**, and 25H2 Home and Pro until October 12, 2027.

Windows Latest also says it has been told Microsoft will soon start installing 26H2 automatically on PCs near or past end of support. That's the outlet's reporting, and Microsoft hasn't announced it.
